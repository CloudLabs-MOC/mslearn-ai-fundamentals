## Question

During speech interaction with the agent, what happens when the application status changes to **Processing…**?

## Options

Option 1 : The agent deletes the conversation history
Option 2 : The application converts speech to text and submits it to the model as a prompt
Option 3 : The application downloads audio files from Azure Storage
Option 4 : The model generates speech directly without text conversion

## Answers

Option 2

## Correct Answer Feedback

Option 2 is the correct answer. During the Processing state, the application uses speech-to-text to convert spoken input into text before sending it to the model.

## Incorrect Answer Feedback

Selected option is incorrect. Option 2 is the correct answer.
