# Module 6a: Get started with information extraction in Microsoft Foundry

### Overall Estimated Timing: 45 Minutes

## Overview

In this lab, you will explore how to use Microsoft Foundry and Azure AI Content Understanding to extract meaningful information from documents and images using prebuilt AI analyzers. You will create a Microsoft Foundry project and use the Content Understanding playground to analyze sample documents and real-world PCB images with analyzers such as OCR/Read, Layout, and Receipt. You'll compare how each analyzer extracts progressively richer information-from raw text and document structure to business-specific fields-and review the generated markdown, tables, extracted fields, and JSON output. Finally, you'll examine the automatically generated Python SDK sample code to understand how Azure AI Content Understanding can be integrated into applications for intelligent document processing and automated information extraction.

## Objectives

By the end of this lab, you will be able to:

1. **Create a Microsoft Foundry project:** Set up a Microsoft Foundry project and provision the Azure resources required to use Azure AI Content Understanding.

2. **Analyze documents and images using Azure AI Content Understanding:** Use the OCR/Read, Layout, and Receipt analyzers in the Content Understanding playground to extract information from sample documents and PCB images.

3. **Compare different document analysis capabilities:** Understand how OCR/Read, Layout, and Receipt analyzers provide progressively richer insights by extracting text, document structure, tables, and business-specific fields.

4. **Review structured analysis results:** Examine markdown output, extracted paragraphs, tables, fields, and raw JSON responses generated by Azure AI Content Understanding.

5. **Understand Python SDK integration:** Review the generated Python SDK sample code to learn how applications authenticate with Azure AI Content Understanding, submit documents for analysis, and process structured analysis results programmatically.

## Architecture

This lab demonstrates how **Microsoft Foundry** and **Azure AI Content Understanding** work together to transform unstructured documents and images into structured, machine-readable information using prebuilt analyzers and developer tools.

1. **Microsoft Foundry Project:** A centralized workspace used to provision Azure AI resources, manage projects, and access Azure AI Content Understanding within Microsoft Foundry.

2. **Azure AI Content Understanding:** A document and image analysis service that uses prebuilt AI analyzers to extract text, document structure, and business-specific information from a variety of content types.

3. **OCR/Read Analyzer:** Extracts text from documents and images, making printed and handwritten content available for downstream processing and analysis.

4. **Layout Analyzer:** Identifies the structural elements of a document, including paragraphs, tables, reading order, and page layout, providing a richer representation of document content.

5. **Receipt Analyzer:** Extracts structured business information from receipts, including merchants, dates, totals, purchased items, and other key-value fields that can be consumed by applications.

6. **Content Understanding Playground:** An interactive interface in Microsoft Foundry used to upload documents and images, run different analyzers, compare results, and inspect markdown, extracted fields, tables, and JSON output.

7. **Python SDK Integration:** Automatically generated sample code that demonstrates how applications authenticate with Azure AI Content Understanding, submit documents for asynchronous analysis, and retrieve structured JSON results using the Azure AI Content Understanding SDK.

8. **Structured Analysis Results:** Machine-readable outputs—including extracted text, paragraphs, tables, business fields, markdown, and JSON—that enable intelligent document processing, workflow automation, and integration with downstream business applications.

## Explanation of Components

1. **Microsoft Foundry Project:**

   Serves as the central workspace for developing AI solutions by provisioning Azure AI resources, managing projects, and accessing Azure AI Content Understanding and other AI services within Microsoft Foundry.

2. **Azure AI Content Understanding:**

   An AI-powered service that analyzes documents and images using prebuilt analyzers to extract structured information from unstructured content, enabling intelligent document processing and information extraction.

3. **OCR/Read Analyzer:**

   Extracts text from documents and images while preserving reading order, making printed and handwritten content available for search, analysis, and downstream AI workflows.

4. **Layout Analyzer:**

   Identifies the structural organization of a document by detecting paragraphs, tables, page layout, and reading order, enabling applications to understand how information is arranged within a document.

5. **Receipt Analyzer:**

   Extracts structured business information from receipts, including merchant details, transaction dates, purchased items, taxes, totals, and other key-value fields, making receipt processing suitable for automation.

6. **Content Understanding Playground:**

   An interactive interface in Microsoft Foundry that allows users to upload documents and images, execute different analyzers, compare analysis results, and inspect extracted markdown, tables, fields, and JSON output.

7. **Structured Analysis Results:**

   The AI-generated output returned by Azure AI Content Understanding, including extracted text, paragraphs, tables, document structure, business fields, markdown representations, and raw JSON that can be consumed by applications and automation workflows.

8. **Python SDK Integration:**

   Automatically generated sample code that demonstrates how developers can authenticate with Azure AI Content Understanding, submit documents for asynchronous analysis, invoke prebuilt analyzers, and process structured JSON results using the Azure AI Content Understanding SDK.

9. **Azure AI Content Understanding SDK:**

   A developer library that simplifies interaction with Azure AI Content Understanding by providing client APIs for authentication, document submission, long-running analysis operations, and retrieval of structured analysis results within Python applications.

10. **Intelligent Document Processing Applications:**

    Business applications and automation workflows that consume the structured outputs generated by Azure AI Content Understanding to support document digitization, data extraction, search, compliance, business process automation, and other AI-powered document processing scenarios.
