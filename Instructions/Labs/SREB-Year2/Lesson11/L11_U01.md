# Lesson 11: Clustering with Azure SQL and Azure ML

### Estimated Timing: 60 Minutes

## Lab overview

In this lab, you connect Azure SQL data from the `TrafficCounts_SC` table into Azure ML Studio as a data asset, clean and normalize traffic volume features, and build a K-means clustering pipeline in Azure ML Designer.  
You train and assign clusters to traffic data, run the pipeline job, and inspect results to identify patterns in traffic flow and congestion clusters.
