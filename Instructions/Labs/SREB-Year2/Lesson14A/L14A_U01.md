# Lesson 14A: Time Series Forecasting with Regression

### Estimated Timing: 60 Minutes

## Overview

In this lab, you will use Azure Machine Learning Designer to build and execute a machine learning pipeline for time series forecasting. You will create and configure datasets, train a regression model, evaluate prediction accuracy, and generate scored results using traffic data stored in Azure SQL Database. Additionally, you will export prediction outputs back to Azure SQL Database for further analysis and validation.
