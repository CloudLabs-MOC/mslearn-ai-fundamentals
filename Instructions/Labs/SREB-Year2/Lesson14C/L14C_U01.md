### Overview

In this lab, you will use Azure Machine Learning Designer to build a K-Means clustering pipeline for grouping road segments based on traffic patterns. You will create datasets from Azure SQL Database, configure and train a clustering model, and assign traffic records to clusters using operational metrics. Additionally, you will export clustering results back to Azure SQL Database to analyze traffic behavior and support smart city traffic operations.
