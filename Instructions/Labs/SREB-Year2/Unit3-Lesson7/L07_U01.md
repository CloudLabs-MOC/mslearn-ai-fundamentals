# Lesson 07: Challenge Guide - Introduction to Computer Vision 

### Estimated Timing: 120 Minutes

## Overview

Welcome to Introduction to Computer Vision Challenge. In this lab, students will work with logistics data to understand how machine learning models can be used to make predictions and how those predictions can be displayed in a dashboard.

You will:

- Train a Random Forest–style model using Azure Machine Learning Studio
- Review model evaluation metrics and feature importance
- Export prediction results
- Build a simple dashboard in Power BI to interpret and explore the results

This lesson includes guided, step-by-step instructions. Follow each section carefully and complete actions as instructed

## Your Task

You are acting as a data analyst for a logistics company. The goal is to predict delivery outcomes (such as delays) and present the results in a clear dashboard that supports decision-making.

You will complete this task by first building a machine learning pipeline in Azure and then visualizing the results in Power BI

## Part 1: Access Azure Machine Learning Studio

1. Open a web browser and navigate to:

    ```
    https://ml.azure.com/
    ```

2. Sign in using the Azure credentials provided by your instructor.

3. Once logged in, ensure you are in the correct Azure subscription and resource group.

4. Open the existing Azure Machine Learning Workspace that was created in a previous lesson.

**Note:** A workspace is your central hub where datasets, models, pipelines, and jobs are managed.

## Part 2: Build the Machine Learning Pipeline

1. From the left navigation menu in Azure ML Studio, select Pipelines.

1. Create or open a pipeline that uses the provided logistics dataset.
Add and connect the following components in order:

1. Clean Missing Data

- Split Data (training and testing)
- Multiclass Decision Forest (Random Forest equivalent)
- Score Model
- Evaluate Model
- Export Data

1. Configure the Multiclass Decision Forest component with these parameters:

- Trainer mode: SingleParameter
- Number of decision trees: 100
- Maximum depth: 32
- Minimum samples per leaf node: 16
- Resampling method: Bagging

1. Save the pipeline and click Run to start the job.

## Part 3: Evaluate the Model

1. Once the pipeline run is complete, open the completed job.

1. Select the Evaluate Model component.

1. Review the evaluation metrics, including:

- R² (Coefficient of Determination)
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)

1. Review Permutation Feature Importance to understand which features (such as distance, traffic, or weather) influenced predictions the most.

## Part 4: Export Prediction Results

1. From the completed pipeline run, locate the Convert to CSV output.

1. Open Outputs + Logs.

1. Register the results dataset using default settings and provide a recognizable name.

1. Navigate to Assets → Data in Azure ML Studio.

1. Open the registered dataset and select View in datastore browser.

1. Download the resulting CSV file to your local machine.

## Part 5: Build the Dashboard in Power BI

1. Open Power BI Desktop on your computer.

1. Select Home → Get Data → Text/CSV.

1. Import the CSV file exported from Azure Machine Learning.

1. Review the dataset fields in the Data pane on the right.

    - Fields marked with Σ indicate numeric columns.

1. Create visuals to represent prediction results, such as:

    - Counts of predicted delivery outcomes
    - Risk or confidence levels
    - Comparisons across routes or regions

1. Add slicers or filters to allow users to interact with the dashboard.

1. Arrange visuals clearly so key insights are easy to identify at a glance.

## Part 6: Reflection

After completing the dashboard, answer the following questions in your lesson handout:

1. How does a dashboard help someone understand model predictions faster than a spreadsheet?
1. How could biased or incomplete data affect decisions made using this dashboard?
1. If a model’s prediction disagrees with human judgment, how should that situation be handled?
1. Identify one scenario where the model’s predictions might be unreliable and explain why.

## Conclusion

In this lesson, you:

- Trained a machine learning model using logistics data
- Evaluated model performance and feature importance
- Exported prediction results from Azure Machine Learning
- Built a dashboard in Power BI to communicate insights
- This end-to-end workflow demonstrates how AI models and dashboards work together to support informed, real-world decision-making.
