## Task 3: Creating a New Designer Workflow

In this task, you create a new pipeline in Azure ML Designer, add the Robot_Logistics dataset, select relevant columns, split the data, and set up a Two-Class Decision Forest model for training and evaluation to predict delivery delays.

1. In Azure ML Studio, select **Designer (1)** from the left navigation menu, then under the **New pipeline** section (Classic prebuilt), click **+ Create a new pipeline using classic prebuilt components (2)**.

    ![](../images/U3-L5-13.png)

1. A pipeline designer panel will open. To update the name of the pipeline, click on **pencil (1)** icon, provide draft name as **Delivery Robot (2)** and draft description as **Delivery Robot (3)**. Then, click on **Save (4)**.

    ![](../images/U3-L5-14.png)

1. Under the **Data** tab, find your dataset **Robot_Logistics** and drag it onto the pipeline canvas to use it as the starting point of your machine learning workflow.

    ![](../images/U3-L5-15.png)

1. Right-click on the dataset module and select **Preview data (1)**. A data window will open, showing all columns and sample rows, including features such as *location_x, location_y, distance, load_weight, num_obstacles, traffic_density, and delay_label*. After reviewing the data, click on **Close (2)**.

    ![](../images/U3-L5-16.png)

1. Click the **Component (1)** tab, use the search bar to find **Select Columns in Dataset (2)**, select it **(3)** from the results, and drag it onto the pipeline canvas.

    ![](../images/U3-L5-17.png)

1. Connect **Data output** port of the **Robot_Logistics** to the **Dataset** port of **Select Columns in Dataset**.

    ![](../images/U3-L5-18.png)

1. Double-click on **Select Columns in Dataset (1)** module, then in the left pane, click on **Edit column (2)**.

    ![](../images/U3-L5-19.png)

1. In the Select Columns window, copy and paste below **columns name (1)** and click on Enter. Then, click on **Save (2)**.

    ```
    location_x, location_y, distance, load_weight, num_obstacles, traffic_density, delay_label
    ```

    ![](../images/U3-L5-20.png)

1. Verify the **columns names (1)** selected appears in Select Columns in Dataset pane, then click on **Close (2)** icon on the top right to close.

    ![](../images/U3-L5-21.png)

1. Enter **Split Data (1)** in the search bar, select the **Split Data (2)** module from the results, and drag it onto the pipeline canvas below **Select Columns in Dataset**.

    ![](../images/U3-L5-22.png)

1. Connect the **Result dataset** output of the **Select Columns in Dataset** module to the **Dataset** input of **Split Data**.

    ![](../images/U3-L5-23.png)

1. Double-click on **Split Data (1)** module and provide the following values:

    - Splitting mode: **Split Rows (2)**
    - Fraction of rows in the first output data: `0.8` **(3)**
    - Randomized split: **True (4)**    
    - Random seed: **42 (5)**
    - Stratified split: **False (6)**
    - Click on **Close (7)**

    ![](../images/U3-L5-24.png)
    
1. Enter **Two-class decision forest (1)** in the search bar, select the **Two-class decision forest (2)** module from the results, and drag it onto the pipeline canvas below **Split Data**.

    ![](../images/U3-L5-25.png)
    
1. Enter **Train Model (1)** in the search bar, select the **Train Model (2)** module from the results, and drag it onto the pipeline canvas below **Two-class decision forest**.

    ![](../images/U3-L5-26.png)
    
1. Connect **Untrained model** port of the **Two-class decision forest** to the **Untrained model** port of **Train Model (1)**.
    - Connect **Result dataset** port of the **Split Data** to the **Dataset** port of **Train Model (2)**.

    ![](../images/U3-L5-27.png)
    
1. Double-click on **Train Model (1)** module, then in the left pane, click on **Edit column (2)**.

    ![](../images/U3-L5-28.png)
    
1. Type the column name **delay_label (1)** and click on **Save (2)**.

    ![](../images/U3-L5-29.png)
    
1. Verify the **columns names** selected appears in Train Model pane, then click on **Close** icon on the top right to close.

    ![](../images/U3-L5-30.png)
    
1. Enter **Score Model (1)** in the search bar, select the **Score Model (2)** module from the results, and drag it onto the pipeline canvas below **Train Model**.

    ![](../images/U3-L5-31.png)

1. Connect **Trained model** port of the **Train Model** to the **Trained model** port of **Score Model (1)**.
    - Connect **Result dataset** port of the **Split Data** to the **Dataset** port of **Score Model (2)**.

    ![](../images/U3-L5-32.png)

1. Enter **Evaluate Model (1)** in the search bar, select the **Evaluate Model (2)** module from the results, and drag it onto the pipeline canvas below **Score Model**.

    ![](../images/U3-L5-33.png)
    
1. Connect **Scored dataset** port of the **Score Model** to the **Scored dataset** port of **Evaluate Model**.

    ![](../images/U3-L5-34.png)

## Task 4: Evaluate the Model and Run the Pipeline    

In this task, you configure and submit the pipeline job in Azure ML Designer, select the compute instance, and run the training and evaluation workflow to predict delivery delays using the Robot_Logistics dataset. You monitor the job’s progress until completion.

1. Ensure that your entire pipeline closely matches the layout shown in the screenshot below. Click on **Save (1)** and then select **Configure & Submit (2)**.

    ![](../images/U3-L5-35.png)
    
1. In the **Set up a pipeline job** pane, under the **Basic** section, enter the following details:

    - **Experiment name:** Select *Create new* **(1)**
    - **New experiment name:** `Delivery_Robot_Pipeline` **(2)**
    - **Job display name:** `Delivery Robot` **(3)**
    - Click on **Next (4)**

    ![](../images/U3-L5-36.png)
    
1. In the **Inputs & outputs** section, leave everything as default and click on **Next**.

    ![](../images/U3-L5-37.png)
    
1. In the **Runtime settings** section, choose **Compute instance (1)** as the compute type. Then, under **Select Azure ML compute instance**, pick the running instance named **TestComputeMg<inject key="Deployment ID" enableCopy="false"/> (2)** and click **Next (3)**.

    ![](../images/U3-L5-38.png)
    
1. In the **Review + Submit** section, verify the settings and then click **Submit**.

    ![](../images/U3-L5-39.png)
