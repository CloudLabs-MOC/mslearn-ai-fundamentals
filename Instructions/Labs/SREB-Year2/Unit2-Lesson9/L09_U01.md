# Lesson 09: Predicting Flood Stages Using Azure AutoML

### Estimated Timing: 60 Minutes

## Lab overview

In this lab, you use Azure Automated ML to train a classification model that predicts flood stages from the merged Conway flood dataset. You upload the dataset to Azure ML, configure and run an AutoML experiment (target FloodStageLabel), review the best model and metrics, run a test job, and export the predictions.csv with the predicted flood stages.

## Task 3: Creating a New AutoML Run

In this task, you use Azure Automated ML to train a classifier for FloodStageLabel: register the Conway_Flood_Data dataset, configure and submit an AutoML job (classification task, target column, validation, limits and timeouts, early termination), select serverless Standard_DS11_v2 compute, monitor the run, review the best model and metrics, run a test job, and export predictions.csv.

1. From the left navigation panel under Authoring, select **Automated ML (1)**. On the **Automated ML** dashboard, click the **+ New Automated ML job (2)** button at the top of the screen.

     ![](../images/U2-L9-12.png)

1. Select **Train automatically** and click on **Start configuring job**.

     ![](../images/U2-L9-13.png)

1. In the Basic settings, provide job name as **Conway_Flood_Prediction (1)**, provide experiment name as **Test (2)** and click on **Next (3)**.

     ![](../images/U2-L9-14.png)

1. Under **Select task type**, select **Classification (1)** from the dropdown menu. Next, select **Conway_Flood_Data (2)** data table and click on **Next (3)**.

     ![](../images/U2-L9-15.png)

1. In the **Target column** dropdown, select **FloodStageLabel (String) (1)** — this is the output the model will learn to predict. Under **Validate and test**, set **Validation type** to **Automatic (2)** so Azure ML automatically handles data splitting for training and testing. Keep **Test data** set to **None (3)**, as the automatic validation will already include a holdout portion of data. Next, click on **Limits (4)**.

     ![](../images/U2-L9-16.png)

1. Enter the following values in each section:

    - Max trails: **10 (1)**
    - Max concurrent trials : **1 (2)**
    - Max nodes: **1 (3)**
    - Experiment timeout (minutes): **15 (4)**
    - Iteration timeout (minutes): **15 (5)**
    - Check the box for **Enable early termination (6)**
    - Click **Next (7)** to continue  

     ![](../images/U2-L9-17.png)

1. Enter or select the following values in each section for Compute Configuration:

     - Select compute type: **Serverless (1)**
     - Virtual machine type: **CPU (2)** 
     - Virtual machine tier: **Dedicated (3)**
     - Virtual machine size: **Standard_DS11_v2 (4)**
     - Number of instances: **1 (5)**
     - Click **Next (6)** to continue 

     ![](../images/U2-L9-18.png)

1. Review the settings and click on **Submit training job**.

     ![](../images/U2-L9-19.png)

1. From the left navigation panel under Assets, select **Jobs (1)** and from the Jobs window, select **Test (2)** job.

     ![](../images/U2-L9-20.png)

1. The status of the job will show as running. Wait for 10-15 minutes for the job to complete. Click on **Refresh** button to get the status updated.

     ![](../images/U2-L9-21.png)

1. Once the AutoML job finishes running, the Status in the Properties panel changes to **Completed**, confirming that all model trials have successfully executed. 
    - Under Best model summary, review the model that achieved the highest performance. In this run, the best-performing algorithm is **MaxAbsScaler, XGBoostClassifier**.
    - Check the AUC weighted score to evaluate the model’s accuracy. A score of **1.0000** indicates that the classifier predicted all flood stages correctly for this dataset.

     ![](../images/U2-L9-22.png)

1. Select the **Models + child jobs** tab to open the leaderboard that displays all models Azure trained during the experiment.

     ![](../images/U2-L9-23.png)
