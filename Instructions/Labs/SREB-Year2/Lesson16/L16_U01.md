## Task 5: Scatter Plots and Tables

In this task, you build scatter plots and table visuals to analyze relationships and summarize traffic data. You also customize aggregations and visual properties to improve data interpretation.

    ![](../images/LAB16-Task5-1.png)

## Task 6: Interact with the Slicer

In this task, you apply slicer filters to explore traffic data dynamically and observe how visuals respond to different filter values. Finally, you save the completed report to the Power BI service.

1. Adjust the **Daily Traffic Count slicer (1)** by setting the range between **0 and 250**, then verify that the report visuals are filtered based on the selected range.

    ![](../images/LAB16-Task6-1.png)

1. Observe how: 

    - The **Bar Chart** shows only route types that experience more than 50 vehicles per day. 

    - The **Column Chart** displays only the counts that were under 250. Thus, Secondary roads see more low traffic counts than other types. 

    - The **Scatter Plot** shows only counts between 0 and 250. With this filter, we can clearly see our traffic counts appear to be rounded to the nearest 25 vehicles. 

1. Select **File (1)**, then select **Save (2)** button in Power BI saves your current report to the Power BI cloud (Service) so you can: 

    - View and share dashboards online 

    - Embed them into websites or apps 

    - Schedule data refreshes 

    - Access reports on mobile 

    - Collaborate with teammates or stakeholders
