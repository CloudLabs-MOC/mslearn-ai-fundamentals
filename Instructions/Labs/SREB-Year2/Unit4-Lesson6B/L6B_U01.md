# Lesson 6C: Using Azure on Large Manufacturing Data

### Estimated Timing: 60 Minutes

## Lab overview

In this lab, you will use Azure Machine Learning Designer to build and execute a machine learning pipeline using a large manufacturing dataset. You will prepare and transform manufacturing data, configure a two-class classification model, and train the model to predict whether human intervention is required in robotic operations. Additionally, you will evaluate model performance and analyze feature importance to understand which manufacturing factors most influence prediction outcomes.
