### Task 1: Set Up Your First Cloud Database and Ask Smart Questions with SQL

1. On the Azure portal, search for **Azure SQL Database (1)**. From the search results under **Services**, click on **Azure SQL Database (2)**.

    ![](../images/U1-L7-01.png)

1. In the SQL databases page, click on **+ Create (1)** and select **SQL database (2)** from the list.

    ![](../images/U1-L7-02.png)

1. Select the resource group **SREB-U1-Lab7 (1)**, provide the database name as **SmartCityDB-<inject key="Deployment ID" enableCopy="false" /> (2)** and click on **Create new (3)** to create new SQL server.

    ![](../images/U1-L7-03.png)

1. In the SQL Database server creation page, provide the following details:

    - Server name: **smartcity-server-<inject key="Deployment ID" enableCopy="false" /> (1)**
    - Location: **<inject key="Region" enableCopy="false" /> (2)**
    - Authentication method: **Use SQL authentication (3)**
    - Server admin login: **mysqladmin (4)**
    - Password: **Srebazure@9 (5)**
    - Confirm password: **Srebazure@9 (6)**
    - Click on **OK (7)**.

    ![](../images/U1-L7-04.png)

1. You will be taken back to the SQL database creation page. Notice that **smartcity-server-<inject key="Deployment ID" enableCopy="false" /> (1)** is now selected as the server. For SQL elastic pool, select as **No (2)**, select the workload environment as **Production (3)**. Select **Configure database (4)** to choose the right compute and storage options for your database.

    ![](../images/U1-L7-05.png)

1. In the configure page, select the **General purpose (Most budget friendly) (1)** option from the list, select **Serverless (2)** compute tier and click on **Apply (3)**.

    ![](../images/U1-L7-06.png)

1. Now you are back to the SQL database creation page, select **Locally-redundant backup storage (1)** and click on **Review + create (2)**.

    ![](../images/U1-L7-07.png)

1. On the review page, verify the details and click on **Create** to create the SQL database.

    ![](../images/U1-L7-08.png)

1. Wait for the deployment to complete. You can click on **Go to resource** to navigate to the SQL database instance you just created.

    ![](../images/U1-L7-09.png)

1. Before connecting to this database using Query Editor, you must allow your client IP through the Azure firewall. To do that, click on **Set server firewall**.

    ![](../images/U1-L7-10.png)

1. Select **Selected networks (1)**, then click on **Add your client IPv4 address (2)**.

    ![](../images/U1-L7-11.png)

1. Scroll down and confirm that your **IP address (1)** is added, then click the check-box to **Allow Azure services and resources to access this server (2)**, and click on **Save (3)**.

    ![](../images/U1-L7-12.png)

1. On the Azure portal, search for **Azure SQL Database (1)**. From the search results under **Services**, click on **Azure SQL Database (2)**.

    ![](../images/U1-L7-13.png)

1. Select the SQL database you just created, **SmartCityDB-<inject key="Deployment ID" enableCopy="false" /> (1)**.

    ![](../images/U1-L7-14.png)

1. Click on **Query editor (preview) (1)** from the left-hand menu. In the Query editor page, select **SQL authentication (2)**, provide the username as **mysqladmin (3)** and password as **Srebazure@9 (4)**, then click on **Connect (5)**.

    ![](../images/U1-L7-15.png)

1. Click on **New Query** to open a new query file.

    ![](../images/U1-L7-17.png)

1. After logging in, go to file explorer in your VM and navigate to **C:\AllFiles\Unit1-Lesson 7-Introduction to Databases & Transportation Data** folder path. Open the file named **Create_Query** using notepad. Copy the SQL query from that file.

    ![](../images/U1-L7-16.png)

    >**Note:** If you face copy-paste issue, click on **3 dots** on top-right corner and enable **VM Native Clipboard**. Then try copy-pasting the query again.
    >
    > ![](../images/vm-native-clipboard.png)

1. Paste the SQL query into the query editor and click on **Run** to execute the query. Check the status of the query and make sure it is **Succeeded (2)**, click on **Tables (3)** from left explorer panel to see the newly created table named **TrafficCounts_SC**.

    ![](../images/U1-L7-18.png)

1. Click on **New Query** to open a new query file.

    ![](../images/U1-L7-19.png)

1. Again, navigate to file explorer in your VM and navigate to **C:\AllFiles\Unit1-Lesson 7-Introduction to Databases & Transportation Data** folder path. Open the file named **TrafficCounts_SC_Inserts** using notepad. Copy the SQL query from that file.

    ![](../images/U1-L7-20.png)

    >**Note:** If you face copy-paste issue, click on **3 dots** on top-right corner and enable **VM Native Clipboard**. Then try copy-pasting the query again.
    >
    > ![](../images/vm-native-clipboard.png)

1. Paste the SQL query into the query editor and click on **Run (1)** to execute the query. Check the status of the query and make sure it is **Succeeded (2)**. You should see the message - **Affected rows: 1000, Query executed successfully**. This confirms all 1,000 records were inserted into the TrafficCounts_SC table.

    ![](../images/U1-L7-21.png)

1. Click on **New Query** to open a new query file.

    ![](../images/U1-L7-22.png)

1. Copy and paste the below **SQL query (1)** which will retrieve all rows and columns from the **TrafficCounts_SC** table, and click on **Run (2)** to execute the query. You should see all rows of data in the **Results (3)** set. This confirms that the table was created successfully and the dataset of 1,000 rows has been loaded.

    ```sql
    SELECT * FROM dbo.TrafficCounts_SC;
    ```

    ![](../images/U1-L7-23.png)
