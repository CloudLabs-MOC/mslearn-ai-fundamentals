# Lesson 09: Challenge Guide - Healthcare Data Visualization in Power BI

### Estimated Timing: 90 Minutes

## Overview

Welcome to the Healthcare Data Visualization Challenge. In this lab, students will work with healthcare datasets to create interactive dashboards and explore how visualization choices influence interpretation and decision-making.

You will:

* Import and explore a healthcare dataset in Power BI
* Create healthcare-focused visualizations and dashboard elements
* Apply appropriate aggregation methods to healthcare data
* Use slicers and filters to explore different perspectives
* Evaluate whether visualizations support or potentially mislead conclusions

This lesson includes challenge-based activities. Follow each section carefully and complete the required tasks.

## Your Task

You are acting as a healthcare data analyst responsible for presenting healthcare information to hospital administrators.

Your goal is to build a dashboard that helps users understand healthcare trends while also identifying the limitations, assumptions, and potential biases that can influence decision-making.

## Part 1: Explore the Healthcare Dataset

1. Open Power BI Desktop.

2. Import a healthcare dataset into Power BI. You can find the file in path **C:\AllFiles\Unit 5-Lesson 9-Healthcare Data Visualization in Power BI**.

3. Review the available columns, data types, and values.

4. Identify which fields are numerical, categorical, and descriptive.

5. Consider which fields may be useful for healthcare analysis and visualization.

## Part 2: Build the Healthcare Dashboard

1. Create a dashboard using the imported healthcare dataset.

2. Include the following visualizations:

   * One bar chart
   * One scatter plot
   * One KPI card
   * One slicer

3. Review the default summarization settings and adjust them where necessary.

4. Ensure each visualization answers a meaningful healthcare question.

5. Arrange the visuals to create a clear and informative dashboard.

## Part 3: Interact and Analyze

1. Use slicers and filters to explore different views of the data.

2. Observe how filtering changes the interpretation of the dashboard.

3. Identify patterns, trends, or relationships visible in the data.

4. Consider whether the selected visualizations provide enough context to support conclusions.

## Part 4: Evaluate the Dashboard

1. Review each visualization and determine whether it accurately represents the data.

2. Identify any visualizations that could be misleading.

3. Consider what information may be missing from the dashboard.

4. Evaluate whether the dashboard would be appropriate for healthcare decision-making.

## Part 5: Reflection

After completing the dashboard, answer the following questions:

1. What pattern appears strongest in your dashboard?

2. Which visualization could be misleading and why?

3. What important information is missing?

4. Would this dashboard be safe for clinical decision-making?

5. How can data visualizations influence the conclusions people make?

## Conclusion

In this lesson, you:

* Imported and explored a healthcare dataset in Power BI
* Created healthcare-focused visualizations and dashboard elements
* Applied appropriate aggregation methods to healthcare data
* Used slicers and filters to investigate patterns and trends
* Evaluated how visualizations can support or mislead decision-making

This challenge demonstrated how healthcare dashboards can help communicate insights while highlighting the importance of interpreting visualizations critically and understanding their limitations.
