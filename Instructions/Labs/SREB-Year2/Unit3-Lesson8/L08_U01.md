# Lesson 08: Embedded Trucking Dashboard and Operational Optimization 

### Estimated Timing: 60 Minutes

## Lab overview

In this lab, you are going to provision Power BI Embedded, create a workspace and semantic model from a CSV data source, and build interactive visuals to analyze trucking data. You assemble these visuals into an interactive dashboard, use cross-filtering to explore delays, cargo types, distances, and weather impacts, and save the interactive report.
