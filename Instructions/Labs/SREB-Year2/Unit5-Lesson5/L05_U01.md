Welcome to the Healthcare Model Comparison Challenge. In this challenge, you will continue building upon the machine learning pipeline in Azure Machine Learning Designer.

Your goal is to compare multiple machine learning models, evaluate their performance using healthcare-focused metrics, and determine which model would be most appropriate for identifying stroke risk.

## Your Mission

You are acting as a Healthcare AI Analyst evaluating machine learning models used to predict stroke risk.

Your mission is to:

1. Build and evaluate a Logistic Regression model using healthcare data.

2. Interpret model evaluation metrics to understand predictive performance.

3. Extend the existing pipeline with a second machine learning model.

4. Compare the performance of both models using the same dataset.

5. Determine which model is more appropriate for predicting stroke risk in a healthcare setting.

## Challenge: Compare and Evaluate Healthcare Prediction Models

You have successfully built and evaluated a Logistic Regression model for stroke prediction.

Using your existing pipeline and dataset, continue your investigation by exploring how a different machine learning algorithm performs on the same healthcare data.

### Challenge Requirements

Using the existing pipeline:

- Add a second classification model.
- Ensure both models use the same training and testing datasets.
- Train, score, and evaluate both models.
- Compare the evaluation metrics produced by each model.
- Determine which model would be more appropriate for predicting stroke risk.

## Part 1: Extend the Existing Pipeline

1. Open the machine learning pipeline you created in the previous task.

2. Add the following components to extend the existing pipeline:

   - Two-Class Decision Forest
   - Train Model
   - Score Model

3. Configure the Decision Forest model to predict the **stroke** outcome using the same healthcare dataset.

   - Connect the **Two-Class Decision Forest** component to the new **Train Model** component.
   - Connect the training output from **Split Data** to the new **Train Model** component.
   - Set the label column to **stroke**.
   - Connect the trained model to the new **Score Model** component.
   - Connect the testing output from **Split Data** to the new **Score Model** component.

4. Update the evaluation process to compare both models.

   - Connect the **Score Model** output from the Logistic Regression model to **Evaluate Model (Input 1)**.
   - Connect the **Score Model** output from the Decision Forest model to **Evaluate Model (Input 2)**.

5. Ensure both models use the same training and testing datasets so the comparison is fair.

6. Save the pipeline and run it.

## Part 2: Evaluate and Compare Models

1. Once the pipeline run is complete, open the evaluation results.

2. Review the performance metrics generated for both models.

3. Compare the following metrics:

   - Accuracy
   - Precision
   - Recall
   - F1 Score
   - AUC

4. Identify which model:

   - Detected more stroke cases
   - Produced fewer false positives
   - Achieved higher recall
   - Achieved higher precision

5. Determine whether the model with the highest accuracy is also the most appropriate model for healthcare predictions.
